# Archivos de inicialización, variables y expansiones

| Archivo | Descripción |
|---------|-------------|
| `0-alias` | Crea un alias llamado `ls` con el valor `rm -f *` |
| `1-hello_you` | Imprime `hello` seguido del usuario actual de Linux |
| `2-path` | Agrega `/action` al final de la variable `PATH` |
| `3-paths` | Cuenta la cantidad de directorios en la variable `PATH` |
| `4-global_variables` | Lista las variables de entorno (globales) |
| `5-local_variables` | Lista todas las variables locales, de entorno y las funciones |
| `6-create_local_variable` | Crea la variable local `BEST` con el valor `School` |
| `7-create_global_variable` | Crea la variable global `BEST` con el valor `School` |
| `8-true_knowledge` | Imprime la suma de 128 y el valor de `TRUEKNOWLEDGE` |
| `9-divide_and_rule` | Imprime el resultado de `POWER` dividido por `DIVIDE` |

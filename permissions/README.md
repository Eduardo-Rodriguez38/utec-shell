# permissions

## 0-iam_betty
Cambia el usuario actual al usuario betty.

## 1-who_am_i
Imprime el nombre de usuario efectivo del usuario actual.

## 3-new_owner
Cambia el propietario del archivo hello al usuario betty.

## 4-empty
Crea un archivo vacío llamado hello.

## 5-execute
Añade permiso de ejecución al propietario del archivo hello.

## 6-multiple_permissions
Añade permiso de ejecución al propietario y al grupo, y permiso de lectura a otros, al archivo hello.
